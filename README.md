# FUTURE_PE_03
Persona-driven AI chatbots built using prompt engineering as part of a Prompt Engineering Internship at Future Interns. Includes Study Tutor, Skincare Analyst, and Café Guide personas with structured prompts and UX-focused documentation.

Persona-Driven AI Chatbots using Prompt Engineering
This repository documents my third and final task from the Prompt Engineering Internship at Future Interns.
The project focuses on designing and deploying persona-based AI chatbots using structured prompt engineering and no-code tools.

🤖 Chatbots Implemented
AI Study Tutor – Supportive, step-by-step academic assistance
AI Skincare Analyst (Skin Sense) – Friendly skincare guidance with clear safety boundaries
AI Café Guide – Conversational recommendations based on user mood and preferences

🧠 Key Highlights
Persona design with consistent tone and behavior
System-level prompt instructions for control and guardrails
Conversational UX and fallback handling
Deployment using Custom GPTs
Live embedding of a chatbot into a Wix Studio website

This project demonstrates how prompt engineering can be used to build ethical, user-focused, real-world AI chatbot experiences without traditional coding or paid APIs.
